### Modding info

This mod is made using the source code of vanilla SPD. It's exactly as you might expect: exactly SPD but with a few changes. Internally, the code remains mostly the same with no gigantic structure changes.

If you can mod vanilla SPD, then you can certainly mod this mod too if you wish (for whatever reason). If you don't know how to mod vanilla SPD, you might want to read the 'readme' on their source code and go from there. you will need some java knowledge if you wish to get something big done.



## FAQ

**Q: Why did you name it matt edition? most PD/SPD mods name it like X PD/SPD**  
A: Technically I could take the title of kaizo or harder SPD. But let's be real here: if I take that title, it's a pretty bold statement that I'd rather not make. Other than that I'm not quite sure what to call it? So i just... slammed my name onto it and simply named SPD Matt Edition.

**Q: Why did you make it so hard?!**  
A: In all fairness: I thought vanilla SPD was sometimes a bit... too forgiving or easy, especially on the early game parts. The goal of this mod was to simply offer a bit more of a challenge in general. And the reason for buffing bosses as much as I did is because they aren't that big of a challenge, especially the first two bosses. Even as a veteran you can expect a quick death with no challenges enabled.

**Q: This one change or update made it nearly impossible!**  
A: I... try to balance some stuff. Sometimes this gets a bit out of hand. Often I'll notice it quickly myself and rebalance it in the next update. If this is not the case and it's a serious issue, you can report it to notify me. Expect alot of balance swings throughout the updates as I eventually find the correct balance.

**Q: Are you going to add alot more new content?**  
A: Debatable. Adding a few new enemies, maybe a new debuff or more is already happening. I also added a few new items already, but don't plan on adding many more. As for new regions, bosses, or quests... I doubt I will. But only the future will tell.

**Q: Do you do sneakpeeks, beta's, or anything similair?**  
A: No. As of now I don't and I don't plan to either. If a decent community grows for this mod, I might consider it though.

**Q: I have a suggestion or pull request!**  
A: Suggestions are welcome, but not guaranteed to be implemented. Just like vanilla SPD I do not accept pull requests as I wish to make everything myself.

**Q: Looking at the source code, I feel like you used AI here?**  
A: I'm a honest man and not gonna lie. In some cases I do tend to use some AI, be it fixing a bug or crash that my brain doesn't understand, or a (somewhat) complex thing I want to implement. As for the coding ratio between me and a AI, its about 70/30, and I myself always come up with any ideas or changes. I'm not using and never will use a Generative AI making sprites for this mod. All sprites, custom music, tilesets, and descriptions are always guaranteed to be fully 100% made by me.

**Q: Is this badge even possible?**  
A: I did make a few new tricky badges compared to vanilla. They might be extremely hard, or nearly impossible. Some of these badges have not been tested for their difficulty and are solely made because someone in the vanilla SPD community managed to achieve it, others were created for completionist sake. But of course, this isn't vanilla SPD, and you may not be the best PD player to live and be able to achieve this. In the future I might reconsider any badges I have made.
